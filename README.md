# Условия сотрудничества: съёмные теплоизоляционные чехлы

Статический сайт-демо с проектом условий: роли и процесс, ставки, объёмы и график набора, загрузка исполнителей, договор, отчётность, риски. Есть калькулятор потока (пересчитывает таблицы на странице).

**Сайт:** <https://alexpror.github.io/i_shell_demo/>  
**Репозиторий:** i_shell_demo

Версия 1.0. Обезличенное демо: без названий компании и оборудования, значения в примерах иллюстративные.

## Состав

- `index.html` - страница
- `style.css` - оформление (печатная версия через `@media print`)
- `calc.js` - формулы калькулятора и таблицы
- `.nojekyll` - отключает обработку Jekyll на GitHub Pages

Публикация: GitHub Pages из ветки `main`, корень репозитория.

## Локальный просмотр

Откройте `index.html` в браузере или:

```
python -m http.server 8080
```

## Допущения расчётов

- Средняя позиция 4,9 м² (по первой партии из четырёх позиций).
- Выработка исполнителя 6–10 м² в день: база 6, потенциал 10 (штатный сотрудник по оценке главного конструктора делает около 10 м² за 8-часовой день). 21 рабочий день в месяц, полная загрузка.
- Объём не фиксирован: заказчик распределяет его между всеми конструкторами, страница считает посильный объём группы и сроки заказчика (середина ноября, 7 рабочих дней).
- Срок позиции: площадь / выработка, округлённая вверх, минимум 1 рабочий день.
- В договоре гарантируется не больше 85% мощности группы (исполнители × выработка × рабочие дни).
- Число исполнителей на объём: объём / (выработка × рабочие дни × загрузка), округляется вверх (500 м² в месяц: 4 при 6 м² в день, 3 при 10).
- Ставка по договору: `(ставка исполнителю + ставка проверки) / (1 - налог УСН)`; во втором варианте ставка исполнителю делится на `(1 - налог самозанятого)`.

Все значения меняются в калькуляторе на странице и уточняются по итогам первой партии.
